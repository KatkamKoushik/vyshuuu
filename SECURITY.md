## Reporting a Vulnerability

We take the security and integrity of **VYSHUUU** seriously. If you discover a security vulnerability or exploit, please help us resolve it responsibly:

1. **Do not create public GitHub issues** for security vulnerabilities.
2. Email the maintainer directly at: `koushikkatkam@gmail.com`.
3. Include:
   * A description of the vulnerability and its potential impact
   * Step-by-step reproduction instructions or a minimal proof-of-concept
   * Proposed mitigation or fix, if available

### Response Timeline
* We will acknowledge receipt of your report within 48 hours.
* We will provide a status update and estimated resolution timeline after investigating.
* Once the vulnerability is resolved, a patch will be deployed and appropriate credit provided.
